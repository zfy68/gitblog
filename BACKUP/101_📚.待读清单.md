## 微信读书可读

来自上述 X 帖回复，目前能在微信读书打开的中文版。

- [ ] [《方舟》](https://weread.qq.com/web/reader/b1132730813ab9a9fg012df1)（『方舟』，夕木春央 / 佳辰 译）
  - **为什么读**：封闭空间里的本格推理，把一群人放进会逐渐被水淹没的地下建筑，看人在极限处境里如何选择。
  - **阅读建议**：先读这一本，再读《十戒》《乐园》；注意避开剧透。章节停顿清楚，适合利用碎片时间一章章读。微信读书有佳辰译本，可直接打开。

- [ ] [《白》](https://weread.qq.com/web/reader/a34322d0813ab71f5g0140b5)（『すべての、白いものたちの』，韩江 / 胡椒筒 译）
  - **为什么读**：以「白色」为线索写成的短章，既像小说也像散文诗，写记忆、哀悼，以及日常里那些洁净却易逝的事物。
  - **阅读建议**：短章结构很适合带娃间隙读一两节，不必一次读完。微信读书为胡椒筒译本。

- [ ] [《火车》](https://weread.qq.com/web/reader/c3e322a0813ab6e82g017293)（『火車』，宫部美雪）
  - **为什么读**：宫部美雪代表作之一，写泡沫经济背景下一个普通上班族被卷入信贷事件后的处境与选择，推理和社会小说兼有。
  - **阅读建议**：务必避开剧透。章节停顿清楚，适合碎片阅读。微信读书为南海出版公司版本。

- [ ] [《如果世上不再有猫》](https://weread.qq.com/web/reader/6c932130813ab91b1g01941d)（『世界から猫が消えたなら』，川村元气 / 王蕴洁 译）
  - **为什么读**：篇幅不长，用「如果世界上少一样东西」的设定，问什么东西对自己真正重要。
  - **阅读建议**：体量小，一两天的碎片时间往往就能读完。有同名电影，想对照的话建议先读书。微信读书为王蕴洁译本。

- [ ] [《理想国》](https://weread.qq.com/web/reader/22c32a305dd66222c91ebc5)（『国家』，柏拉图 / 张竹明 译，译林版）
  - **为什么读**：讨论正义、教育和理想城邦的哲学经典，是理解西方政治思想的起点之一。
  - **阅读建议**：不必一次读完，清醒时读一小节即可，犯困时不适合硬啃。译林张竹明译本较通行；另有[何祥迪译的果麦版](https://weread.qq.com/web/reader/2e1325e0813ab78c4g013897)等其他译本，选一种读下去即可。

- [ ] [《小妇人》](https://weread.qq.com/web/reader/8b5325005d0eca8b53fcf90)（『若草物語』，路易莎·梅·奥尔科特 / 刘春英、陈玉立 译，译林版）
  - **为什么读**：写马奇家四姐妹的成长与家庭生活，温暖、章节分明，是经典的成长小说。
  - **阅读建议**：译林版可直接读。喜欢的话再读续作[《小男子汉》](https://weread.qq.com/web/reader/b6c32310717111d6b6c9a50)、[《乔的男孩们》](https://weread.qq.com/web/reader/0d0329607209256c0d0c5c6)。

- [ ] [《圣诞颂歌》](https://weread.qq.com/web/reader/b1e324605dddbdb1e47f6c5)（『クリスマス・キャロル』，狄更斯 / 邓嘉宛 译）
  - **为什么读**：狄更斯的短篇经典，写一个吝啬的人在圣诞夜里被改变，篇幅短、故事完整。
  - **阅读建议**：现在读正好赶上年尾。邓嘉宛译本或[汪倜然中英双语插图本](https://weread.qq.com/web/reader/04c321f07182db4f04ceeb1)都可以；一个晚上或两三个碎片时段往往就能读完。

- [ ] [《在我曾经最美的时候：茨木则子诗集》](https://weread.qq.com/web/reader/73832210813ab7e28g011b3f)（含『自分の感受性くらい』，茨木则子 / 熊韵 译）
  - **为什么读**：原帖推荐的是诗「自分の感受性くらい」（集中译作「自己的感受力至少要」），写的是把感受力掌握在自己手里。微信读书没有同名单行本，这首诗收在这本诗集里。
  - **阅读建议**：直接打开目录里的对应栏目即可，不必按顺序读完全书。诗天生适合碎片时间。

## 微信读书待上架

书城有条目，但目前是待上架或已下架，打开可能读不了。上架后再勾选开读。

- [ ] [《十二国记(1-15)》](https://weread.qq.com/web/reader/20e32380811e77e4cg0147c2)（『十二国記』，小野不由美；简介称王蕴洁 译，尖端出版）
  - **为什么读**：以中国古典为底色的异世界长篇，写身份、命运与治国，是日本奇幻的代表作之一。
  - **阅读建议**：部头大，适合一卷一卷读。建议从《月之影 影之海》开始，不要先跳到后期的《白银之墟 玄之月》。上架前可先不开坑。

- [ ] [《浪击而不沉》](https://weread.qq.com/web/reader/d9132d70721ead46d919c99)（『たゆたえども沈まず』，原田舞叶 / 星野空 译，新星出版社）
  - **为什么读**：以十九世纪巴黎为舞台，写梵高兄弟与日本画商林忠正的交会，是带艺术史背景的小说。
  - **阅读建议**：等微信读书重新上架，或先找纸书。中等篇幅，有连续一点的时间再读更顺。

- [ ] [《银河英雄传说》](https://weread.qq.com/web/reader/73732c205e420b737a8868e)（『銀河英雄伝説』，田中芳树 / 袁斌 译）
  - **为什么读**：田中芳树的太空史诗，写帝国与同盟之间的战略、政治与人物，是亚洲科幻的经典长篇。
  - **阅读建议**：体量很大，适合当作长期读物，一章一章来，不必赶着读完。条目目前待上架，上架后再开始更合适。

- [ ] [《德尔菲尼亚战记》](https://weread.qq.com/web/reader/a0732490811e1df6bg01036f)（『デルフィニア戦記』，茅田砂胡）
  - **为什么读**：茅田砂胡的长篇奇幻战记，卷数多，是日式奇幻里的经典系列之一。
  - **阅读建议**：投入不小，目前待上架，等能稳定读到再决定是否开坑。

## 暂无中文电子版

这次在微信读书没搜到对应译本，可先记在这里，有纸书、日文版或其他平台再读。

- [ ] 《十戒》（『十戒』，夕木春央）
  - **为什么读**：原帖回复建议与《方舟》《乐园》连着读的本格向作品。
  - **阅读建议**：放在《方舟》之后、《乐园》之前。暂无微信读书译本，先不要剧透。

- [ ] 《乐园》（『楽園』，夕木春央）
  - **为什么读**：同上，是回复里建议连读的第三本。
  - **阅读建议**：读完《方舟》《十戒》再读。暂无微信读书译本。

- [ ] 《初恋收起来的日子》（『初恋をしまう日』，町田そのこ；中文书名暂按日文直译，未见通行电子版译名）
  - **为什么读**：町田そのこ的小说常写普通人的情感，原帖里被推荐给想看「会哭的书」的人。
  - **阅读建议**：暂无微信读书译本。篇幅若按她一贯的中长篇，有连续一点的晚上再读更合适。

- [ ] 《小鸟与理梦人》（『小鳥とリムジン』，小川糸；台湾繁体译名）
  - **为什么读**：小川糸一贯的温暖日常与人情，原帖里称它是温情的故事。
  - **阅读建议**：该书暂无微信读书译本。若想先感受她的文风，她的《山茶文具店》等在微信读书有。

- [ ] 《成濑跑过整座城市》（『成瀬は都を駆け抜ける』，宮島未奈；中文书名暂按日文意译，微信读书未见上架）
  - **为什么读**：成濑三部作的第二部，青春轻快，写一个我行我素的高中女生。
  - **阅读建议**：建议先读第一部『成瀬は天下を取りにいく』（简体《成濑要征服世界》），再读这一本。微信读书暂无这两部。

- [ ] 《预言的岛》（『予言の島』，澤村伊智；中文书名暂按日文直译）
  - **为什么读**：原帖里称它再读时会别有意味，是那种第一遍和第二遍观感会不同的作品。
  - **阅读建议**：务必避开剧透。暂无微信读书译本。

- [ ] 《妖精森林的小不点》（『ハクメイとミコチ』，樫木祐人）
  - **为什么读**：描写真人大小的小人在山野里过日子的漫画，节奏舒缓，生活气足。
  - **阅读建议**：适合累的时候翻几话。微信读书未见官方版本。
