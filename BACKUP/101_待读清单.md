# [待读清单](https://github.com/zfy68/gitblog/issues/101)

## 微信读书可读

- [ ] [《方舟》](https://weread.qq.com/web/reader/b1132730813ab9a9fg012df1)
  - **为什么读**：封闭空间里的本格推理，把一群人放进会逐渐被水淹没的地下建筑，看人在极限处境里如何选择。
  - **阅读建议**：先读这一本，再读《十戒》《乐园》；注意避开剧透。章节停顿清楚，适合利用碎片时间一章章读。

- [ ] [《白》](https://weread.qq.com/web/reader/a34322d0813ab71f5g0140b5)
  - **为什么读**：以「白色」为线索写成的短章，既像小说也像散文诗，写记忆、哀悼，以及日常里那些洁净却易逝的事物。
  - **阅读建议**：短章结构很适合带娃间隙读一两节，不必一次读完。

- [ ] [《火车》](https://weread.qq.com/web/reader/c3e322a0813ab6e82g017293)
  - **为什么读**：宫部美雪代表作之一，写泡沫经济背景下一个普通上班族被卷入信贷事件后的处境与选择，推理和社会小说兼有。
  - **阅读建议**：务必避开剧透。章节停顿清楚，适合碎片阅读。

- [ ] [《如果世上不再有猫》](https://weread.qq.com/web/reader/6c932130813ab91b1g01941d)
  - **为什么读**：篇幅不长，用「如果世界上少一样东西」的设定，问什么东西对自己真正重要。
  - **阅读建议**：体量小，一两天的碎片时间往往就能读完。有同名电影，想对照的话建议先读书。

- [ ] [《理想国》](https://weread.qq.com/web/reader/22c32a305dd66222c91ebc5)
  - **为什么读**：讨论正义、教育和理想城邦的哲学经典，是理解西方政治思想的起点之一。
  - **阅读建议**：不必一次读完，清醒时读一小节即可，犯困时不适合硬啃。

- [ ] [《小妇人》](https://weread.qq.com/web/reader/8b5325005d0eca8b53fcf90)
  - **为什么读**：写马奇家四姐妹的成长与家庭生活，温暖、章节分明，是经典的成长小说。
  - **阅读建议**：喜欢的话再读续作[《小男子汉》](https://weread.qq.com/web/reader/b6c32310717111d6b6c9a50)、[《乔的男孩们》](https://weread.qq.com/web/reader/0d0329607209256c0d0c5c6)。

- [ ] [《圣诞颂歌》](https://weread.qq.com/web/reader/b1e324605dddbdb1e47f6c5)
  - **为什么读**：狄更斯的短篇经典，写一个吝啬的人在圣诞夜里被改变，篇幅短、故事完整。
  - **阅读建议**：现在读正好赶上年尾。一个晚上或两三个碎片时段往往就能读完。

- [ ] [《在我曾经最美的时候：茨木则子诗集》](https://weread.qq.com/web/reader/73832210813ab7e28g011b3f)
  - **为什么读**：「自分の感受性くらい」（集中译作「自己的感受力至少要」），写的是把感受力掌握在自己手里。
  - **阅读建议**：直接打开目录里的对应栏目即可，不必按顺序读完全书。诗天生适合碎片时间。

## 微信读书待上架

- [ ] [《十二国记(1-15)》](https://weread.qq.com/web/reader/20e32380811e77e4cg0147c2)
  - **为什么读**：以中国古典为底色的异世界长篇，写身份、命运与治国，是日本奇幻的代表作之一。
  - **阅读建议**：部头大，适合一卷一卷读。建议从《月之影 影之海》开始，不要先跳到后期的《白银之墟 玄之月》。上架前可先不开坑。

- [ ] [《浪击而不沉》](https://weread.qq.com/web/reader/d9132d70721ead46d919c99)
  - **为什么读**：以十九世纪巴黎为舞台，写梵高兄弟与日本画商林忠正的交会，是带艺术史背景的小说。
  - **阅读建议**：等微信读书重新上架，或先找纸书。中等篇幅，有连续一点的时间再读更顺。

- [ ] [《银河英雄传说》](https://weread.qq.com/web/reader/73732c205e420b737a8868e)
  - **为什么读**：田中芳树的太空史诗，写帝国与同盟之间的战略、政治与人物，是亚洲科幻的经典长篇。
  - **阅读建议**：体量很大，适合当作长期读物，一章一章来，不必赶着读完。条目目前待上架，上架后再开始更合适。

- [ ] [《德尔菲尼亚战记》](https://weread.qq.com/web/reader/a0732490811e1df6bg01036f)
  - **为什么读**：茅田砂胡的长篇奇幻战记，卷数多，是日式奇幻里的经典系列之一。
  - **阅读建议**：投入不小，目前待上架，等能稳定读到再决定是否开坑。

## 暂无中文电子版

- [ ] 《十戒》
  - **为什么读**：与《方舟》《乐园》连着读的本格向作品。
  - **阅读建议**：放在《方舟》之后、《乐园》之前。先不要剧透。

- [ ] 《乐园》
  - **为什么读**：与《方舟》《十戒》连读的第三本。
  - **阅读建议**：读完《方舟》《十戒》再读。

- [ ] 《初恋收起来的日子》
  - **为什么读**：町田そのこ的小说常写普通人的情感，适合想看「会哭的书」的人。
  - **阅读建议**：篇幅若按她一贯的中长篇，有连续一点的晚上再读更合适。

- [ ] 《小鸟与理梦人》
  - **为什么读**：小川糸一贯的温暖日常与人情。
  - **阅读建议**：若想先感受她的文风，可先读她的《山茶文具店》。

- [ ] 《成濑跑过整座城市》
  - **为什么读**：成濑三部作的第二部，青春轻快，写一个我行我素的高中女生。
  - **阅读建议**：建议先读第一部『成瀬は天下を取りにいく』（简体《成濑要征服世界》），再读这一本。

- [ ] 《预言的岛》
  - **为什么读**：再读时会别有意味，是那种第一遍和第二遍观感会不同的作品。
  - **阅读建议**：务必避开剧透。

- [ ] 《妖精森林的小不点》
  - **为什么读**：描写真人大小的小人在山野里过日子的漫画，节奏舒缓，生活气足。
  - **阅读建议**：适合累的时候翻几话。

### 读到一半，建议优先续上

- [ ] [《美国儿科学会育儿百科（第七版）》](https://weread.qq.com/web/reader/0b632700813ab7158g01664e)
  - **为什么读**：偏权威的儿科与养育工具书，不是要一气读完的故事。
  - **阅读建议**：已经接近读完，剩下的部分当作查询手册即可。仓库里已有读书笔记 #100。新生儿阶段可优先翻睡眠、喂养、哭闹相关章节。

- [ ] [《中国现代诗歌经典选读》](https://weread.qq.com/web/reader/6ca329105aaa836ca644ec8)
  - **为什么读**：现代诗选本，适合在碎片时间一首一首读。
  - **阅读建议**：已经过半，抽空把剩余篇目读完即可，不必连续啃。

- [ ] [《豆豆三部曲（普通人的改命路线图）》](https://weread.qq.com/web/reader/f5532100813abc110g010081)
  - **为什么读**：以规则、人性与选择见长的长篇小说集，其中《遥远的救世主》尤为人所知。
  - **阅读建议**：从上次停下的地方续读即可。仓库里已有本套笔记 #97，以及《遥远的救世主》笔记 #90。

- [ ] [《明亮的夜晚》](https://weread.qq.com/web/reader/2db32930813ab80f9g0165a3)
  - **为什么读**：韩国作家崔恩荣的小说，笔触细腻，常写女性的生活与彼此的牵绊。
  - **阅读建议**：已经开了头，适合用碎片时间慢慢续。不必赶速度。

- [ ] [《丰乳肥臀》](https://weread.qq.com/web/reader/ea532d2071938fb5ea51430)
  - **为什么读**：莫言的长篇代表作之一，以一个家庭和一位母亲的视角写二十世纪中国的变迁，篇幅长、分量重。
  - **阅读建议**：刚开头。这部不宜当睡前轻松读物，有相对完整的时段再推进更合适。

- [ ] [《认知觉醒：开启自我改变的原动力》](https://weread.qq.com/web/reader/6a732ce07201202c6a7b30a)
  - **为什么读**：面向自我认知和习惯改变的通识读物，章节较短。
  - **阅读建议**：几乎还没开始，可当作碎片时间的轻量阅读；不必一次读完。

- [ ] [《厌女（增订本）》](https://weread.qq.com/web/reader/67632250813ab6d7bg014522)
  - **为什么读**：上野千鹤子关于厌女文化的社会学著作，用来理解性别结构和日常里的偏见。
  - **阅读建议**：已开始但进度仍为 0%，可以从任一章接着读，概念性文字适合清醒时看。

### 未开始·和带娃更相关

- [ ] [《父母的语言：3000万词汇塑造更强大的学习型大脑》](https://weread.qq.com/web/reader/6ab32c905defcd6abe7224d)

  - **阅读建议**：很多内容在幼儿期之后也会用到。可先浏览整体框架，需要时再翻对应章节。

- [ ] [《卡尔·威特的教育》](https://weread.qq.com/web/reader/be9328c0718ea4fbbe96fa8)

  - **阅读建议**：有明显的时代局限，建议带着辨识读，不必全盘照搬。
